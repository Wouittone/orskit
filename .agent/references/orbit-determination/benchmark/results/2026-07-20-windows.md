# Local benchmark record: 2026-07-20

Three release-mode samples of 10,000 independent Cartesian position EKF
corrections on this Windows workspace. The reported throughput uses the median
elapsed time; JVM startup and Gradle invocation are excluded because the timer
is inside each harness.

Environment: AMD Ryzen 7 3800X (8 cores / 16 logical processors), Windows
10.0.26200.0, Rust 1.96.1, and OpenJDK 25.0.3 LTS.
