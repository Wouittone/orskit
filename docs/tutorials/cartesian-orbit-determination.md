# Cartesian position orbit determination

The current orbit-determination boundary performs sequential Cartesian EKF or
UKF updates over an application-selected `Propagator<CartesianState>`. This
tutorial generates one synthetic GCRF position observation and assimilates it
with the EKF. Its [complete example](../../crates/orbit-determination/examples/cartesian_position_od.rs)
is compiled as part of the workspace's all-target checks.

Run it from the repository root:

```powershell
cargo run -p orbit-determination --example cartesian_position_od --locked
```

## Scenario

The example uses metres, metres per second, and diagonal standard deviations in
those same units. Both the prior and its covariance are Earth-centered GCRF at
zero seconds on Hifitime's TAI timeline. The observation is GCRF Cartesian
position 60 SI seconds later. An illustrative measurement offset of
`[3, -2, 1] m` is added to a state generated by the same two-body propagator;
this makes the example deterministic but does **not** provide independent
accuracy evidence.

The caller constructs:

1. an `Orbit<CartesianState>` prior and `CartesianCovariance`;
2. an `EllipticKeplerPropagator` that owns the chosen Earth point-mass problem;
3. positive-definite Cartesian process noise;
4. a `CartesianPositionObservation` with a positive-definite
   `PositionCovariance`; and
5. an `ExtendedKalmanFilter`, followed by `estimate(&observation)`.

Every state, covariance, and observation must use the same frame. The filter
propagates the prior to the observation's absolute epoch and returns the
posterior at that epoch. Construction, propagation, covariance factorization,
and the correction all return `Result`; the example propagates failures with
`?`.

## Current limitations

This is a deliberately narrow Cartesian observation boundary, not the broader
`measurements` participant/signal-path API. It currently supports sequential
position observations only. Public covariance constructors accept positive
component-wise standard deviations and therefore create diagonal covariance;
correlated covariance ingestion is not exposed. The EKF obtains a scaled
central finite-difference transition Jacobian, while the UKF propagates sigma
points. There is no analytical STM, batch least squares, parameter estimation,
measurement generation, smoothing, clock/media model, Earth-orientation-backed
transform, or operational accuracy claim.

The two-body example problem also omits perturbations and is valid only for
bound elliptic motion. A production observation must come from an independently
qualified sensor pipeline and must carry justified covariance. Consult the
[parity ledger](../../.agent/PARITY.md) before treating any estimation workflow
as validated.
